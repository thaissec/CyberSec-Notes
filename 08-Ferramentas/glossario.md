# Glossário

| Termo | Significado |
|---|---|
| **ACK** | Flag TCP de confirmação; terceiro passo do handshake |
| **APT** | Advanced Persistent Threat: grupo sofisticado de ataques prolongados |
| **ARP** | Descobre o MAC de um IP na rede local |
| **ARP spoofing** | O invasor responde falsamente a pedidos ARP para interceptar tráfego |
| **Banner** | Texto que um serviço envia ao conectar, muitas vezes revelando software e versão |
| **Brute force** | Adivinhar senhas testando muitas combinações |
| **C2** | Comando e Controle: canal pelo qual o atacante comanda o malware |
| **CIA** | Confidencialidade, Integridade e Disponibilidade |
| **Community string** | "Senha" do SNMP; `public` é insegura |
| **CVE** | Identificador público de uma vulnerabilidade |
| **CVSS** | Nota de 0 a 10 da gravidade técnica |
| **DDoS** | Negação de serviço distribuída |
| **DHCP** | Entrega IP, máscara, gateway e DNS automaticamente |
| **DN** | Distinguished Name: endereço completo de um item no LDAP |
| **DNS** | Traduz nomes de domínio em IPs |
| **Enumeração** | Extração de detalhes de serviços |
| **EternalBlue** | Falha do SMBv1 (CVE-2017-0144) que permite execução remota de código |
| **Exfiltração** | Saída não autorizada de dados |
| **Falso positivo** | Problema apontado que na verdade não existe |
| **Firewall** | Permite ou bloqueia tráfego por regras |
| **Footprinting** | Levantamento de informações sobre um alvo |
| **Gateway** | Roteador que leva o tráfego da rede local a outras redes |
| **GVM / OpenVAS** | Ferramentas de código aberto para scan de vulnerabilidades |
| **Handshake (three-way)** | SYN, SYN-ACK, ACK |
| **IDS / IPS** | Detecção / prevenção de intrusão |
| **LDAP** | Serviço de diretório (usuários e grupos) |
| **LGPD** | Lei Geral de Proteção de Dados |
| **MAC** | Endereço físico da placa de rede |
| **Máscara de sub-rede** | Define bits de rede e de host (`/24`) |
| **MFA** | Autenticação multifator |
| **MIB / OID** | Dicionário e endereço numérico dos objetos do SNMP |
| **MITM** | Man-in-the-middle |
| **NAT** | Tradução de IPs privados em um IP público |
| **NSE** | Nmap Scripting Engine |
| **Null session** | Conexão SMB sem usuário e senha |
| **NVT** | Teste individual do OpenVAS |
| **OSINT** | Inteligência de fontes abertas |
| **pcap** | Arquivo de captura de pacotes |
| **Persistência** | Manter o acesso após reinicialização |
| **Phishing** | Mensagem falsa para obter dados ou induzir execução |
| **QoD** | Quality of Detection: confiança do resultado no OpenVAS |
| **Ransomware** | Malware que criptografa arquivos e exige resgate |
| **SMB** | Compartilhamento de arquivos (porta 445) |
| **SNMP** | Monitoramento de dispositivos (161/UDP) |
| **SPF / DKIM / DMARC** | Autenticação de e-mail via registros DNS |
| **Superfície de ataque** | Pontos por onde um sistema pode ser atacado |
| **SYN** | Flag TCP que inicia a conexão |
| **Tática / Técnica** | No MITRE: objetivo / método |
| **TTL** | Tempo de vida de um pacote (ou de um cache DNS) |
| **Wiper** | Malware que apaga ou corrompe dados |
